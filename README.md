# Minecraft 模组云端同步（MinecraftModsCloudSync）

一套双端工具，用于在 **服务端（维护者）** 与 **客户端（玩家）** 之间同步 Minecraft 模组、资源包、配置等文件。

- **服务端工具**：管理服务器文件仓库，检测改动、制作待办、把新客户端内容同步上服务器、导出客户端配置文件。
- **客户端工具**：导入服务端下发的配置文件，自动检查并应用更新。

## 功能特性

### 服务端工具
- **多服务器管理**：同一界面管理多台服务器，每台服务器独立 SFTP 连接与远程目录；支持拖入版本文件夹 / `.minecraft` / 启动器快捷方式（PCL2 / PCL CE / HMCL）自动识别版本并入库；服务器列表支持搜索过滤、多选与反选、右键重命名 / 移除、侧边栏折叠。
- **更新服务端（C2S）**：自动创建服务端快照并对比本地新客户端，差异树展示新增（绿）/ 替换（橙）/ 删除（红）/ 旧版残留；并行扫描 + 内存缓存加速；支持忽略、手动标注发送目标（双端 / 服务端 / 客户端 / 跳过）、模组运行环境分析（jar 元数据 + MC 百科标注）。
- **发布待办（S2C）**：自动检测服务端改动并生成发布清单（新增 / 替换 / 删除 / 旧版残留），可禁用 / 启用 / 批注任务，发布后自动更新基线。
- **服务器设置**：SFTP 连接信息、远程目录（服务端文件仓库根目录 / 待办目录 / 客户端文件目录，均为绝对路径）、差异排除规则、客户端模组关键词、客户端软件设置下发（自动检查间隔 / 开机自启 / 系统通知）。
- **导出客户端配置**：为每台服务器生成加密的配置文件（含唯一编号），授权编号同步到服务器。
- **日志**：按天查看、按时间段导出；日志按服务端 / 客户端隔离存储。

### 客户端工具
- **导入服务器配置**：支持拖入 `.mcscf` 配置文件自动导入（重复导入会提示覆盖），或通过文件对话框导入。
- **自动更新检查与应用**：按设定间隔自动检查各服务器更新，可一键应用（下载 / 替换 / 删除），服务端下发的软件设置自动生效。
- **已知版本库**：拖入 `.minecraft` / `versions` 文件夹 / 启动器快捷方式自动识别版本；「选择已知版本…」快速设置客户端根目录。
- **安全**：服务器 SFTP 信息加密保存、日志脱敏（客户端日志不出现任何 SFTP 服务器细节）。

### 通用
- 深色 / 浅色双主题（跟随系统）。
- 所有表格 / 树表头支持拖动调整列序，列分隔线清晰。
- 搜索框统一支持 `*` 通配，实时过滤。
- 客户端与服务端启动即最大化；关闭窗口最小化到系统托盘。
- 开机自启（最小化到托盘）。

## 使用流程（简要）

1. **服务端**：添加服务器 → 在「服务器设置」填写 SFTP 连接信息与远程目录 → 在「更新服务端」页把新客户端内容同步到服务器文件仓库 → 在「发布待办」页检测改动并发布待办 → 在「导出客户端配置」页生成配置文件发给玩家。
2. **客户端**：导入服务端下发的配置文件 → 选择本地 Minecraft 根目录 → 「立即检查更新」→「应用更新」。

## 目录结构

```
app_common/     # 双端共用：配置、日志、SFTP、快照、版本解析、任务清单、模组分析等
client_app/     # 客户端：主窗口 + 更新引擎
server_app/     # 服务端：主窗口 + 各工作流页面
assets/         # 图标素材
installer/      # Inno Setup 安装脚本
build.py        # PyInstaller 打包脚本（生成单文件 exe）
```

## 构建与打包

```bash
# 1) 安装依赖
pip install -r requirements.txt

# 2) 打包客户端与服务端单文件 exe（输出到 dist/）
python build.py

# 3) 编译 Windows 安装程序（需安装 Inno Setup）
ISCC installer/setup.iss
```

Release 产物：
- `MinecraftSyncClient.exe` — 客户端单文件
- `MinecraftSyncServer.exe` — 服务端单文件
- `MinecraftModsCloudSync_Setup_1.0.0.exe` — Windows 安装程序

## 技术栈

- Python 3 + PySide6（Qt）图形界面
- paramiko（SFTP）
- PyInstaller（单文件打包）
- Inno Setup（安装程序）

## 说明

- 服务端与客户端通过 SFTP 交换数据：待办清单（`manifest.json`）、客户端文件仓库、授权编号清单。
- 客户端配置文件为加密存储，仅服务端导出的配置文件可被客户端识别。
